# GitHub Rules

## Pull Requests

- Never run `gh pr create` (or open a PR through any other tool or API) unless the user explicitly asks for it.
- Show the proposed title, body, and base branch for review before creating the PR.
- Always assign PRs to @devert
- Do not include "Created with Claude Code" in PR descriptions

## Commits

- Do not include "Co-Authored-By" lines in commit messages
